# Overview
The ```AndroidLiquidglassView``` library is an Android library that implements the iOS 26 LiquidGlass effect in Android Views

## Project Requirements
|  Min SDK  |    Java    |
|-----------|------------|
| `API 24+` | `Java 21+` |

## Integration

### Add Dependencies
In your module's `build.gradle` file, add the dependency:
```groovy
dependencies {
   implementation 'com.qmdeve.liquidglass:core:1.1.0'
}
```
If it's `build.gradle.kts`:
```kotlin
dependencies {
   implementation("com.qmdeve.liquidglass:core:1.1.0")
}
```
